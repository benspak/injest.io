# Chrome Extension Icons

The extension requires icon files at:
- `icons/icon16.png` (16x16)
- `icons/icon48.png` (48x48)
- `icons/icon128.png` (128x128)

## Quick Setup

Create an `icons` folder and add icon images, or use a placeholder generator:

1. Create `icons/` directory
2. Add your icon files or generate placeholders
3. Icons should be PNG format

For MVP, you can use any simple icon or emoji converted to PNG.

Injest Capture Settings

Configure your external API connection

The base URL of the external API. Default: https://api.injest.io/api/external

Generate from the dashboard under External API Access. Paste the key here.

How to get your API key

  1. Log in to your Injest web app
  2. Open the dashboard and locate the External API Access card
  3. Generate a new API key (or copy your existing key)
  4. Paste the API key in the field above

Keyboard Shortcut

Press Cmd+Shift+V (Mac) or Ctrl+Shift+V (Windows/Linux) to capture clipboard content.

Note: The shortcut may need to be configured in Chrome's extension keyboard shortcuts settings.
